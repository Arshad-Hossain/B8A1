
# B8A1 - Assignment: Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment demonstrates practical knowledge of TypeScript fundamentals, advanced type features, asynchronous programming, and Object-Oriented Programming (OOP).

The solutions are implemented in a single TypeScript file named `solutions.ts`, following the assignment requirements.

## Problem Solving

The assignment covers the following 8 problems:

| Problem | Topic | Description |
|---|---|---|
| 1 | Optional Parameters | Implement `multiplyValue()` with a default multiplier of 2. |
| 2 | Union Types & Type Narrowing | Implement `processInput()` using `typeof` to handle strings, numbers, and booleans. |
| 3 | Readonly Tuples | Implement `formatCoordinate()` using a readonly tuple. |
| 4 | Generics & Rest Parameters | Implement `concatenateArrays()` to combine multiple arrays of the same type. |
| 5 | Interfaces & Array Filtering | Define the `Course` interface and implement `getPopularCourses()`. |
| 6 | Generics & keyof | Implement `pluckValues()` to extract object property values safely. |
| 7 | OOP & Inheritance | Create `Employee` and `Manager` classes using access modifiers and inheritance. |
| 8 | Promises & Async/Await | Implement `validateAgeAsync()` with Promise-based validation. |
